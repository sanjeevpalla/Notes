### 6. Building the MCP Server From Scratch: Tools & a Prompt

#### 🪜 Step-by-Step — The Complete, Real, Live-Coded Server

> 💡 **Given directly:** *"From fast MCP, I will import Fast MCP... I will first make sure that I'm creating some tools. So, let me first create MCP equals to time track... at the rate mcp.tool, and now I can say def log underscore time, employee name, project, entry date, hours and description."*

```python
from fastmcp import FastMCP

mcp = FastMCP("Time Track")

@mcp.tool()
def log_time(employee_name: str, project: str, entry_date: str, hours: float, description: str) -> dict:
    """Log a new time entry, for a specific employee and project."""
    return db.log_time(employee_name, project, entry_date, hours, description)

@mcp.tool()
def get_timesheet(employee_name: str) -> list[dict]:
    """Get the complete timesheet, for a specific employee."""
    return db.get_timesheet(employee_name)

@mcp.tool()
def get_project_summary(project: str) -> dict:
    """Get a full summary of hours logged, for a specific project."""
    return db.get_project_summary(project)

@mcp.tool()
def list_projects() -> list[str]:
    """List all known projects."""
    return db.list_projects()

@mcp.prompt()
def generate_weekly_report(employee_name: str, week_start: str) -> str:
    """A reusable prompt for generating a complete, weekly time report."""
    return f"Generate a complete weekly time report for {employee_name}, starting {week_start}."

if __name__ == "__main__":
    mcp.run()
```
